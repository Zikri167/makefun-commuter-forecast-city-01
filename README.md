One line of weather for Plippton, a city that does not exist: drizzle all day, 12°C, and a bus shelter that leaks exactly where you stand — as tradition demands. Broadcast-forecast register, bent by one small commuter joke at the end.

## Run it

```sh
node main.ts
```

Writes the single forecast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (103 characters, one line, no trailing newline).
